HGNICE WinGo Analyzer - Android Project

এটি একটি সাধারণ ফলাফল-লগ ও ফ্রিকোয়েন্সি বিশ্লেষক। এটি ভবিষ্যৎ WinGo ফলাফল নিশ্চিতভাবে বলতে পারে না।
Android APK তৈরি:
1. ZIP ফাইলটি Extract করুন।
2. GitHub repository-র Code পেজে প্রকল্পের ভেতরের সব ফাইল ও ফোল্ডার আপলোড করুন।
3. .github/workflows/build-apk.yml ফাইলটি অবশ্যই ওই নির্দিষ্ট পথে রাখুন।
4. Actions > Build Android APK > Run workflow চালান।
5. সফল হলে Artifacts থেকে HGNICE-WinGo-APK ডাউনলোড করুন।
